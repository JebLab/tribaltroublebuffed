The first build of **Tribal Trouble Buffed**, a single-player fork of [Tribal Trouble: Resurrected](https://github.com/Tribal-Trouble/tribaltrouble), which modernised Oddlabs' 2004 game. It is an early pre-release: the new units, buildings and modes are still to come (see the [milestone queue](https://github.com/JebLab/tribaltroublebuffed/blob/revamp/docs/MILESTONES.md)).

## What is in it

- **Rulesets** in the Single-player menu: *Classic* (the 2004 numbers and the 2004 world options only), *Resurrected* (that project's game at the time of the fork) and *Buffed* (this fork's game, which will carry the new content; for now it plays like Resurrected). Campaign and tutorials play under Resurrected.
- **Determinism fixes**: AI unit grouping no longer depends on hash codes, and the simulation uses `StrictMath` where results feed the game state, so a game replays the same way every time.
- Quitting no longer ends with a Steam error. Steam integration is switched off in this fork.
- Behind the scenes: AI-vs-AI matches played without a window under every ruleset, checked for victories and identical checksums on Windows and Linux on every change.

## Running it

Windows only for now. Unzip `TribalTroubleBuffed-v0.1.0-windows.zip` anywhere and run `TribalTrouble\TribalTrouble.exe`; it brings its own Java runtime. The program is not signed, so Windows SmartScreen may warn the first time ("More info", then "Run anyway"). Settings, saves and logs go to `%LOCALAPPDATA%\TribalTrouble`.

Multiplayer menus are inherited from Resurrected and not maintained here.
