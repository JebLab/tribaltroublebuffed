# Milestones — one session each

How this works: each milestone is sized for one working session, run from a prompt in `docs/prompts/` under the rules in [SESSION_RULES.md](SESSION_RULES.md). A session does the milestone, ticks its row (✅), records the outcome in the log at the bottom, commits on `revamp`, pushes, writes the next milestone's prompt and starts that session itself (chain mode is Josh's: manual or free). The launcher always picks the first row without a ✅, so reordering rows reorders the work. Scope: **single-player only**; multiplayer items are parked at the end. Order after M4 is a suggestion and can be reshuffled.

Definition of done for every milestone: it builds (`gradlew build`), the game runs, the change is behind the *Buffed* ruleset or a flag where it alters gameplay, strings exist in every language file, and the log below is updated.
